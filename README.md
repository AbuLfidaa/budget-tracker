This project is intended to track the income and expense of a user and saves automatically in a JSON file.
It has options the user can navigate through which are: add income, add expense, balance, transaction history and quit.
Every meaningful activity are automatically saved in a JSON file, i.e if a file exist in the folder and if not, the program automatically create a file and save every activity in it.
